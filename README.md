I'm an entry-level software engineer with production experience modernizing a government application used across Washington State's justice system. My strongest area is the frontend (Angular, TypeScript, React), but my foundation also covers Java, Spring Boot, REST APIs, and SQL, and I like understanding the whole stack even when I'm focused on the UI.
